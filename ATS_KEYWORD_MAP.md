## Avoid Overclaiming

Do not convert these project/research exposures into unsupported seniority claims:

- Kubernetes / AKS — historical/research infrastructure exposure only unless separately verified for the target application.
- Azure — infrastructure scripts exist in TROOP, but do not present this as production Azure administration experience.
- Machine learning — anomaly detection, RandomForest, and research modules exist; do not present as ML engineering employment.
- Cybersecurity — defensive networking project experience exists; do not claim security-engineer or penetration-testing employment.
- Trading — backtesting/paper/research work exists; do not claim profitable autonomous live trading.
- Java — real project exposure exists in OSRS/RuneLite prototype; Python remains the primary language.
- Luau — real Digital Dreamscape project exposure exists; do not imply general Lua production employment.

## Tailoring Formula

For each application, aim for:

- 5-8 exact high-value keywords from the job description in the summary/skills section;
- 3-6 exact high-value keywords supported by project bullets;
- 2-4 projects selected for direct relevance;
- no keyword that cannot be defended with a concrete example in an interview.
