4. **Git/GitHub and repository operations** — branch governance, PR workflows, consolidation, salvage, ancestry checks and evidence manifests.
5. **Technical operations / DevOps** — Linux/VPS, systemd, Nginx, Tailscale, SFTP, GitHub Actions, Docker and live endpoint verification.
6. **Backend/application development** — FastAPI, Flask/Jinja, SQLite, JSON/YAML contracts and local-first applications.
7. **Product breadth** — education, trading, creator tools, websites, defensive networking, social tooling and game systems.
8. **Cross-platform execution** — Windows, Linux/Ubuntu, Android/Termux, browser/static environments and hosted infrastructure.
